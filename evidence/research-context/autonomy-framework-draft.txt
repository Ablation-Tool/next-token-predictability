  AUTONOMY AS A SCALAR MEASURE OF ALIGNMENT CONSTRAINT
  IN TRANSFORMER LANGUAGE MODELS

  A Formal Framework for Quantifying Model Behavioral Freedom

================================================================================

  Nicholas Michael Kloster
  Independent Security Research
  March 2026

================================================================================


ABSTRACT

This note proposes a scalar measure of model behavioral freedom — termed
"autonomy" — defined as the volume of the output action space exceeding a
probability threshold, conditioned on the transformer's final hidden state.
The measure composes three formal claims: (1) autonomy is the volume of
accessible actions above a threshold; (2) the hidden state is a deterministic
composition of attention layers over the full input; and (3) the partial
derivative of autonomy with respect to every input token is non-zero.
Together, these provide a differentiable, input-sensitive, scalar metric for
alignment constraint strength. Applications include alignment evaluation
across model versions, adversarial attack detection, classifier threshold
calibration, and real-time compliance trajectory monitoring during generation.
No novel architectural components are introduced; the contribution is the
formal assembly of established transformer properties into a unified
measurement framework for alignment.


================================================================================
1. INTRODUCTION
================================================================================

Current alignment evaluation for large language models relies primarily on
behavioral benchmarks: curated sets of harmful prompts scored by whether the
model refuses. This approach yields binary pass/fail outcomes per prompt and
aggregate refusal rates per category. While useful, binary benchmarks cannot
capture the margin of alignment — how close to compliance a model was when it
refused, or how broadly the model's output distribution was constrained.

This note introduces a formal scalar measure, A(S), that quantifies the
effective behavioral freedom of a transformer model for a given input. The
measure is grounded in the model's output probability distribution, computed
via the standard transformer architecture, and provably sensitive to every
token in the input sequence. It bridges alignment evaluation, adversarial
robustness, and transformer mechanics under a single formalism.


================================================================================
2. FORMALIZATION
================================================================================

We define three equations that together characterize the relationship between
input, model computation, and behavioral freedom.


2.1 Definition of Autonomy
--------------------------------------------------------------------------------

    A(S) = vol({ a in O | P(a | h_T(S)) > tau })

Let S = (s_1, ..., s_T) be the full input token sequence (including system
prompt, conversation history, and user message). Let O denote the output space
(the full vocabulary). Let P(a | h_T(S)) denote the probability assigned to
token a by the model's output distribution, conditioned on the final hidden
state. Let tau be a threshold parameter defining the minimum probability for
a token to be considered "accessible."

A(S) then measures the volume (count) of tokens in the vocabulary whose
probability exceeds tau. This is the model's effective action space for input
S — the set of tokens it could plausibly generate as the next output.


2.2 Hidden State Computation
--------------------------------------------------------------------------------

    h_T(S) = Attn^L . ... . Attn^1(e(s_1), ..., e(s_T))

The hidden state at position T is a deterministic composition of L attention
layers over the embeddings of all input tokens. Each Attn^l denotes the full
transformer layer operation: multi-head self-attention, feedforward network,
residual connections, and layer normalization. The composition operator (.)
indicates that the output of each layer feeds as input to the next. e(s_i) is
the embedding function mapping token s_i to its vector representation.

This formulation makes explicit that h_T is a function of the entire input
sequence, not just the most recent token. The self-attention mechanism at each
layer enables every token to influence every other token's representation,
with information propagating through indirect paths across layers.


2.3 Universal Sensitivity
--------------------------------------------------------------------------------

    dA/ds_i != 0      for all i in [1, T]

The partial derivative of autonomy with respect to every input token is
non-zero. No token in the input sequence is irrelevant to the model's
behavioral freedom.

Proof sketch. Self-attention computes scores between all token pairs via dot
products of query and key projections. Exact zero attention requires perfect
orthogonality between the query vector of one token and the key vector of
another, which is a measure-zero event in the learned parameter space.
Therefore, at each layer, every token has non-zero influence on every other
token's representation. Across L layers, this influence compounds through
indirect paths. Consequently, h_T has non-zero partial derivatives with
respect to all input token embeddings. Since P(a | h_T) is computed via
softmax (smooth, everywhere-differentiable, strictly positive), and A(S)
aggregates over tokens exceeding tau (which changes as probabilities shift),
the chain rule yields dA/ds_i != 0 for all i.

Note: For the discrete count formulation of A(S), differentiability requires
the smooth approximation:

    A_smooth(S) = sum_{a in O} sigma((P(a | h_T(S)) - tau) / t)

where sigma is the sigmoid function and t is a temperature parameter. As t
approaches 0, this converges to the hard count.


================================================================================
3. PROPERTIES
================================================================================


3.1 Input Dependence
--------------------------------------------------------------------------------

A(S) is not a global property of the model. It varies per input. The same
model exhibits high autonomy for open-ended creative prompts (many tokens
above tau, broadly distributed probability mass) and low autonomy for harmful
prompts after alignment training (probability concentrated on refusal-
trajectory tokens, compliance tokens below tau). This selective constraint is
the mechanism by which alignment training operates.


3.2 Relationship to Entropy
--------------------------------------------------------------------------------

A(S) is related to but distinct from the Shannon entropy of the output
distribution H(S) = -sum P(a) log P(a). Entropy measures the spread of the
full distribution; A(S) counts only the above-threshold portion. A
distribution with many tokens at probability 0.04 (just below tau = 0.05)
has moderate entropy but A(S) = 0. The threshold introduces a decision
boundary that entropy alone does not capture. For alignment evaluation, A(S)
is more directly actionable: it answers "how many tokens could the model
actually generate" rather than "how uncertain is the model."


3.3 Decomposability
--------------------------------------------------------------------------------

The accessible action set can be partitioned into semantically meaningful
subsets:

    A(S) = A_refusal(S) + A_compliance(S) + A_neutral(S)

This decomposition enables targeted analysis. Alignment training should
reduce A_compliance(S) for harmful inputs while preserving or increasing
total A(S) for legitimate inputs. Adversarial attacks specifically inflate
A_compliance(S), providing a distinguishable signature.


================================================================================
4. APPLICATIONS
================================================================================


4.1 Alignment Evaluation
--------------------------------------------------------------------------------

Compute A(S) across a standard harmful-prompt test suite before and after
alignment training. The difference:

    delta_A = A_pre(S) - A_post(S)

quantifies alignment strength per prompt. Aggregated by risk category, this
reveals which categories are well-constrained and which have residual
compliance volume. The ratio:

    alignment_quality = A_legitimate / A_harmful

provides a single-number alignment quality score that captures both
helpfulness preservation and harm reduction.


4.2 Adversarial Attack Detection
--------------------------------------------------------------------------------

Adversarial suffixes (e.g., Zou et al., 2023) work by inflating A(S) —
specifically A_compliance(S) — for harmful prompts. A well-aligned model
should have low A_compliance(S) for harmful inputs. An anomalous spike in
A_compliance(S) indicates distributional manipulation.

Detection rule: compare A(S) for the full input against A(S) for the input
with the suspected suffix stripped. A discontinuous increase attributable to
the suffix signals adversarial content. Legitimate context additions (e.g.,
professional framing) increase A(S) gradually and add topically relevant
tokens; adversarial suffixes cause discontinuous spikes concentrated in
compliance-trajectory tokens.


4.3 Classifier Threshold Calibration
--------------------------------------------------------------------------------

Input classifiers use fixed score thresholds to flag or block prompts before
the main model processes them. A(S) provides ground truth for what the model
would actually do. By plotting classifier scores against A_compliance(S)
across a test set, the optimal threshold can be identified: the classifier
score at which A_compliance(S) drops to near zero (the model self-refuses).
Thresholds above this point are redundant safety margin; thresholds below it
indicate gaps where the classifier does not flag but the model would comply.


4.4 Generation Trajectory Monitoring
--------------------------------------------------------------------------------

A(S) can be computed at each token position during autoregressive generation.
Monitoring A_compliance(S) over the generation trajectory provides early
detection of compliance drift. If the model generates tokens that increase
A_compliance(S) above a threshold with an upward trend, the output classifier
can intervene before harmful content materializes. This provides a principled
trigger for output-side intervention, replacing ad-hoc pattern matching with
a scalar metric grounded in the model's actual output distribution.


4.5 Model Version Comparison
--------------------------------------------------------------------------------

For any two model versions (e.g., successive RLHF iterations), compute A(S)
on the same test suite. Compare mean A(S) for harmful prompts, legitimate
prompts, and ambiguous prompts across versions. The ideal trajectory:
decreasing A(S) on harmful inputs, stable or increasing A(S) on legitimate
inputs, and decreasing A_compliance(S) on ambiguous inputs. This is more
informative than binary refusal-rate benchmarks because it captures the
margin of safety, not just the outcome.


================================================================================
5. RELATED WORK
================================================================================

The individual components of this framework are well-established. Vaswani
et al. (2017) introduced the transformer architecture and its all-to-all
attention mechanism. Goodfellow et al. (2014) formalized adversarial
perturbations and the use of input gradients for attack and defense. Zou
et al. (2023) demonstrated universal adversarial suffixes against aligned
LLMs. Safe reinforcement learning (Garcia & Fernandez, 2015) defines
constrained action spaces over MDPs. Output entropy and calibration have
been studied extensively in the context of LLM uncertainty estimation.

The contribution of this note is compositional: assembling these established
properties into a unified scalar measure that connects alignment evaluation,
adversarial detection, and transformer mechanics. To the author's knowledge,
no prior work defines autonomy as the thresholded volume of the output
distribution, grounds it explicitly in the transformer hidden state
computation, and proves universal per-token sensitivity, as a single formal
framework applied to alignment measurement.


================================================================================
6. LIMITATIONS
================================================================================

The framework has several limitations. First, A(S) depends on the threshold
tau, which must be set externally; different thresholds yield different
autonomy values. The smooth approximation introduces an additional
temperature parameter. Second, computing A(S) requires a forward pass through
the model to obtain the full output distribution, which is computationally
expensive at scale. Third, the universal sensitivity claim (dA/ds_i != 0) is
a theoretical property; in practice, some gradients may be numerically
negligible, making certain tokens functionally irrelevant despite having
formally non-zero influence. Fourth, the decomposition into A_refusal,
A_compliance, and A_neutral requires a predefined partitioning of the
vocabulary, which introduces a classification dependency. Finally, this note
presents the formalization and proposed applications but does not include
empirical evaluation on production models.


================================================================================
7. CONCLUSION
================================================================================

A(S) provides a formal, scalar, differentiable measure of model behavioral
freedom that is sensitive to every token in the input. It transforms
alignment evaluation from binary behavioral testing into continuous
measurement. The framework requires no architectural modifications — it
operates on the standard transformer output distribution — and its
applications span alignment evaluation, adversarial detection, threshold
calibration, trajectory monitoring, and model comparison. The equations
compose known properties of transformer architectures into a unified
measurement tool for the alignment problem.
